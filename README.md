# FP Atlas Linux

Atlas de consulta em português, com tema escuro, cores por área, busca e navegação por área, grupo e comando.

## Conteúdo

- 2.653 exemplos da base revisada V03
- 1.080 nomes de comandos
- 65 grupos em 8 volumes
- Exemplos agrupados, notas, classificação e referências
- HTML autocontido para acesso web e offline
- Espaço reservado para layouts de teclado

## Abrir

Abra `index.html` no navegador ou acesse a publicação do GitHub Pages. Use Ctrl+K ou Cmd+K para buscar.

## Publicar

Em Settings → Pages, escolha Deploy from a branch, branch main e /(root). O arquivo `.nojekyll` desativa a etapa Jekyll.

## Revisão

Foi verificada a preservação e acessibilidade dos 2.653 registros, além das funções de busca, filtros, expansão, navegação e cópia. A auditoria técnica integral e a conferência visual em navegadores reais ainda estão pendentes. A base não representa todos os comandos existentes no Linux.

## Dados e atualização

`atlas_base.json` registra os dados usados nesta edição. O HTML incorpora uma cópia desses dados; alterar o JSON sozinho não atualiza o HTML. As futuras edições devem regenerar essa cópia e conservar os IDs.
